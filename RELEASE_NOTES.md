# Release notes — v1.0.0

This release packages the final audited reproducibility workflow associated with the manuscript:

**Beyond In-Domain Performance: Cross-Dataset and Cross-Platform Generalization of Social Media Stress Classifiers**

## Included
- six canonical notebooks defining the final manuscript workflow
- documentation of canonical dataset counts and model settings
- scripts for sanitizing prediction outputs
- verification targets for headline results
- PeerJ-ready Data Availability wording
- GitHub/Zenodo metadata templates

## Excluded
- raw Reddit/Twitter text
- pretrained model weights/checkpoints
- obsolete development notebooks
- stale intermediate result streams
- personal Google Drive files

## Important provenance note
The original Colab files were visible in Colab Recent history on 2026-11-04, including the final notebooks last opened on 2026-10-16. Their original Google Drive file IDs subsequently returned 404 because the Drive copies had been deleted. The repository notebooks were recovered from the user's local archive and were cross-checked against that Colab history.

## Canonical MNB note
The final paper uses the reconciled MNB result stream produced by Stage A2 and finalized by notebook 08, not the earlier intermediate MNB stream.
