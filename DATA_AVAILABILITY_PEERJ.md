# PeerJ Computer Science — Data Availability statement

Use the following wording in the manuscript before the Zenodo DOI is minted:

> The datasets analyzed in this study are publicly available from the original sources cited in the manuscript. Code for dataset auditing, model training, external evaluation, statistical analysis, and figure generation is publicly available at GitHub: https://github.com/komalbashir-sketch/stress-generalization. An archived version of the repository will be deposited in Zenodo and the DOI will be added before submission. Raw social-media text is not redistributed beyond the terms of the original dataset sources.

After Zenodo archives release `v1.0.0`, replace the second sentence with:

> Code for dataset auditing, model training, external evaluation, statistical analysis, and figure generation is archived at Zenodo: [ZENODO DOI], with the development repository available at https://github.com/komalbashir-sketch/stress-generalization.

Do not submit the final PeerJ manuscript with `[ZENODO DOI]` unresolved.
