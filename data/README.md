# Data

Raw source datasets are not redistributed in this repository.

The notebooks retrieve the datasets from the public sources cited in the manuscript. For an archival release, record:

- exact source URL,
- retrieval date,
- source repository commit/tag where available,
- SHA-256 checksum of each downloaded raw file.

This is especially important for Reddit Combi because the associated publication reports 3,604 records whereas the public file used by the study contained 3,123.
